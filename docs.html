DOYUNGO MAPS지도관리자

DOYUNGO MAPS API 2.0

MapTiler 지도 타일을 API 키로 보호해서 제공합니다. 키는 관리자 페이지에서 발급합니다.

서버 상태

GET /api/health

지도 타일

GET /api/tiles/{style}/{z}/{x}/{y}.png?key=발급받은키

키는 ?key= 쿼리 또는 x-api-key 헤더로 보냅니다.

style설명확장자
streets일반 지도png
satellite위성 지도jpg
terrain지형 지도png
topo등고선 지도png

예시

curl -H "x-api-key: dyg_xxxxxxxx" \
  https://내도메인/api/tiles/streets/7/108/50.png -o tile.png

Leaflet

L.tileLayer("https://내도메인/api/tiles/streets/{z}/{x}/{y}.png?key=dyg_xxxxxxxx").addTo(map);
